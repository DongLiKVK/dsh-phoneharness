# 地址说明：设置面板里那几行「手机里填这个地址」

面板上那几行**不是输入框**，也不需要你编辑：它们是这台电脑**此刻对外可达的候选入口**，一行一种接入方式，点右侧「复制」把整条 `http://地址:端口` 抄进剪贴板，粘到手机 APK 的配对页即可。

一行只代表一条路，**永远不会三条都对** —— 所以每行都标了三样东西：

| 标记 | 含义 |
| --- | --- |
| 类型胶囊（Tailscale / 局域网 / 虚拟网卡 / 其他 / 本机） | 这条地址走的是哪种网络路径 |
| 「推荐」 | 当前最可能连得上的那条（正在监听 + 类型优先级最高） |
| 「未监听」 | 这条地址此刻**没有**被插件监听，手机填了也连不上（整行会变淡） |

第三行小字是该类型的适用场景，最后一行（仅在未监听时出现）是补救提示。

## 零、从没用过 Tailscale？先看这段

**Tailscale 不是必需组件**，它只是「手机不在同一个 WiFi 时」的一条可选通路。项目默认配置 `bind: loopback,lan,tailscale`，其中 `lan` 让**同一个 WiFi 里开箱即用**；`tailscale` 在没装的机器上会自动跳过，不会报错、不会占端口。

三条不依赖 Tailscale 的路：

| 方案 | 怎么做 | 适合 | 代价 |
| --- | --- | --- | --- |
| **同一 WiFi**（默认） | 手机和电脑连同一个路由器，面板里点「局域网」那条的「复制」 | 家里、办公室、宿舍 | 手机一出门就失效 |
| **手机开热点** | 手机开热点 → 电脑连这个热点 → 仍用「局域网」那条 | 出差、咖啡厅临时用 | 电脑要能连 WiFi；耗手机流量 |
| **内网穿透** | 用 frp / cloudflared / ngrok 把 `127.0.0.1:8737` 映射成一个公网域名，`bind` 收到 `loopback`；手机填那个域名 | 长期在外、又不愿意装组网工具 | 要自己配隧道；域名暴露在公网，务必配 HTTPS 与访问控制 |

### 要走外网（4G / 出差 / 公司网络）→ 装 Tailscale

**为什么是它**：Tailscale 把手机和电脑放进同一条私有网络，两端各拿到一个 **100.x** 地址，设备之间 WireGuard 加密。好处是不用在路由器上做端口转发、不用把 **8737** 暴露到公网，也不依赖某个公网中继站记明文。免费个人版上限 100 台设备，个人用足够。

三步（大约 5 分钟）：

1. **电脑**：打开 <https://tailscale.com/download> 装好，用任意账号（Google / Microsoft / GitHub / 邮箱）登录；
2. **手机**：装同一款 App —— 应用商店搜「Tailscale」，或直接 <https://tailscale.com/download/android>（iOS 用 <https://tailscale.com/download/ios>）——登录**同一个**账号，并在系统里允许它建立 VPN 连接；
3. **回电脑面板**：地址列表会多出「Tailscale」那行（约 5 秒自动刷新），点「复制」，填进 APK 配对页的地址框。

插件设置面板里有同一份引导（「外网接入（可选 · Tailscale）」卡片），并按当前机器状态显示三种徽章：

| 面板徽章 | 含义 | 该做什么 |
| --- | --- | --- |
| **未安装** | 本机没有 <TAILSCALE_IP>/10 网卡 | 按上面三步装电脑版 + 手机版 |
| **已安装 · 未生效** | 有 Tailscale 网卡，但不在 bind 里 | 把 bind 改成 loopback,lan,tailscale 并重启宿主 |
| **已就绪** | 网卡在监听 | 复制那行填进手机，出门也能连 |

> 手机上必须让 Tailscale 常驻（Android 关掉电池优化，iOS 保持 VPN 已连接），否则切后台后地址会断。

> 常见误解：面板里**没有** Tailscale 那行不是装坏了，只是这台机器没有 tailnet 地址。此时「局域网」或「虚拟网卡」才是你的选项。

## 一、每个地址的用途与适用场景

| 类型 | 典型地址 | 判定依据 | 什么场景下用 | 什么时候会失效 |
| --- | --- | --- | --- | --- |
| **Tailscale** | `<TAILSCALE_IP>/10` 段，如 `http://100.x.y.z:8737` | 地址落在 CGNAT 段（`isTailscale()`） | 手机登录**同一个 Tailscale 账号**：外出、4G、换 WiFi 都能连；链路由 Tailscale 端到端加密，不把端口暴露到公网 | 手机没装 / 没登录 Tailscale；这台电脑 Tailscale 掉线；`bind` 里没有 `tailscale` |
| **局域网** | `192.168.x.x`、`10.x.x.x`、`172.16–31.x.x` | RFC1918 私网段（`isPrivate()`） | 手机和电脑**同一个 WiFi / 同一个交换机**，家里、办公室最省事的一条 | 手机切 4G、换到别的 WiFi、电脑重新 DHCP；`bind` 里没有 `lan` |
| **虚拟网卡** | `172.30.x.x`（OPPO 互联）、`192.168.56.x`（VirtualBox）、`172.17.x.x`（Docker）、`172.2x.x.x`（WSL/Hyper-V） | 网卡名命中 `VIRTUAL_IFACE` 正则（vmware / vethernet / docker / wsl / tap / tun / wireguard / zerotier / vgate / devicespace …） | 一般用不上。这类网卡只服务它自己的对端（手机投屏、容器网络、VPN 隧道内部） | 手机连不上属正常：虚拟网卡的地址只有它自己的成员可达 |
| **其他** | 公网 IP、未知网段 | 既不是私网也不是 Tailscale | 把机器放在公网 / 云主机上，并且确实想让它被公网访问 | 需要路由器端口映射或云安全组放行；**默认不推荐** |
| **本机** | `127.0.0.1` | 回环 | 只做本机调试（手机永远连不到） | 手机侧不可用 |

> 「虚拟网卡」这条是本项目踩过的坑：Windows 装了 OPPO 互联（`devicespace.exe` 会拉起一块 Wintun 隧道网卡 `vgate0`）之后，本机多出一个 `172.30.x.x/32`，长得像局域网地址、实际与手机无关。旧版面板把它和真局域网混在一起列，容易误填。现在按「网卡名 + 网段」做启发式分类，并直接标注「虚拟网卡 / 只服务它自己的设备直连」。

## 二、「未监听」是怎么算出来的

插件启动时把配置项 `bind` 解析成一组具体地址（`resolveBind()`），服务器只在这组地址上监听。面板拿到**本机所有网卡地址**，对每条算：

```js
listening = binds.includes('0.0.0.0') || binds.includes('::') || binds.includes(address)
```

- `bind` 写成 `0.0.0.0` 时，所有地址都算在监听（等于对全网开放）；
- `bind` 写成 `loopback,tailscale` 时，只有 `127.0.0.1` 与 `100.x` 那几条在监听，局域网 / 虚拟网卡地址会显示「未监听」；
- 默认值 `loopback,lan,tailscale`：本机、所有私网地址、tailnet 地址都在监听；没装 Tailscale 时那一项解析为空，自动跳过。

好处是：面板不再「列一堆地址让你猜」，而是明确告诉你哪条此刻能用。

## 三、想让某条地址可用

改插件配置里的 `bind`（`~/.dsh/profiles/<profile>/cordis.patch.yml`，或面板设置里的插件配置表单）：

```yaml
- id: dsh-phoneharness
  config:
    port: 8737
    # 只给同一 WiFi 下的手机用（最常见）
    bind: lan,loopback
    # 局域网 + Tailscale 都开
    # bind: lan,tailscale,loopback
    # 任意来源（等于对全网监听，慎用）
    # bind: 0.0.0.0
```

改完重启宿主（或让宿主重新加载该插件），面板 5 秒内会刷新出新的监听状态。

## 四、排错顺序

1. **先看面板**：手机该填的是带「推荐」、或至少没有「未监听」的那条。
2. **手机能打开 `http://地址:端口/health`** → 网络通；打不开 → 防火墙 / 不同网段 / 未监听。
3. **Windows 首次监听会弹防火墙授权**：要允许「专用网络」；只放行公用网络会导致局域网连不上。
4. **同一 WiFi 却显示未监听** → `bind` 里没有 `lan`；改配置或改用 Tailscale。
5. **换 WiFi 后旧地址失效** → DHCP 换了 IP，重新复制新地址；想稳定就给电脑设静态 IP，或统一走 Tailscale。
