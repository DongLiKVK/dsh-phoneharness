# 仿 DeepSeek 官方客户端改造 · 变更记录（v0.5.0）

模板：<DOWNLOADS>/DeepSeek(1).apk（com.deepseek.chat 2.6.1 (279)，纯 Compose）
目标：<PROJECT_ROOT>/android/bin/dsh-phone.apk（com.lc.phoneharness）
本轮版本：versionName 0.5.0 / versionCode 6

## 1. 首页 = 官方「新对话页」
- 顶栏：左 ≡（开抽屉）、右侧 语音喇叭 + ⊕（新建会话），无标题居中。
- 版心：鲸形 logo + 「嗨！今天想聊些什么？」，垂直居中偏上。
- 底部 composer：卡片 28dp 圆角 / 边距 11dp / 占位「发消息或按住说话」15sp；底部两枚座位 chip（模型 V4.1-Flash、权限 完全权限）+ 上传 ⊗ + 语音/发送圆形按钮；下方三格面板 拍照 / 相册 / 文件（77dp 高、16dp 圆角）。
- 发送 → 建会话并进 ChatActivity。

## 2. 抽屉 = 官方历史列表
- 顶部灰底搜索胶囊「搜索对话内容...」+ 放大镜 → 点开全屏搜索页。
- 工作区 chips 行（全部 / 各工作区），点选后列表按工作区过滤，写入 prefs。
- 分组：置顶 / 今天 / 昨天 / 7 天内 / 30 天内 / 更早；今天 组头右侧「多选」。
- 行：仅标题（去掉行内「置顶」「已归档」胶囊与预览行）。
- 底部：圆形头像 + PhoneHarness + 设备名；点整行进设置；⋯ 弹 归档箱 / 刷新列表 / 连接设置 / 设置。

## 3. 多选
- 标题变「选择对话」+ 右侧 ✕；行首空心选择圈，选中蓝底白勾。
- 底部固定条：置顶 | 删除（多选计数「已选 N 个对话」）。

## 4. 搜索页
- 圆形返回 + 胶囊输入框；结果 = 标题 + 正文摘要预览；本地过滤标题/lastText。

## 5. 设置页（SettingsActivity，官方分组结构）
- 品牌卡（logomark + PhoneHarness + v0.5.0，版本号读 App.VERSION_NAME）。
- 分组：连接（电脑连接 / 工作区 / 归档箱）、账户（账号管理 / 数据管理）、应用（语言 / 外观 / 字体大小 / 个性化）、语音（朗读音色）、关于（检查更新 / 服务协议 / 帮助与反馈）。
- 行式：图标 + 标签 + 右灰值 + ›。
- 外观对话框：标题「外观」+ 系统 / 浅色 / 深色 单选 + 分隔线 + 蓝色「确认」→ 落 prefs 并 recreate。
- 字体大小页：圆形返回 + 居中标题；右上 #EDF3FE 预览气泡「预览文字大小」；两段说明；底部 sheet「跟随系统」绿色开关 + A（小）/ 居中「标准」/ A（大）+ 带刻度滑块。

## 6. 对话页
- 用户气泡：右对齐、填充 #EDF3FE（深色 #283142）、圆角≈20dp、最大宽 268dp；行下 复制 / 分享（最后一条用户消息多一项 修改）。
- 助手：全宽无气泡、16dp 边距、Markdown 渲染；脚注「本回答由 AI 生成，内容仅供参考，请仔细甄别」。
- 思考行：无胶囊底色，纯灰文本「已思考（用时 N 秒）· 工具调用 M 次 ›」，chevron 展开后正文灰 + 左侧细竖线 + 工具行折叠卡。
- 操作条：复制 / 赞 / 踩 / 朗读 / 分享 ……… 右端 重新生成↻（接系统 TTS，朗读当前消息）。
- 长按菜单改为锚定浮层：助手 8 项（复制/选择文本/重新生成/喜欢/不喜欢/朗读/分享/举报），用户 3-4 项（复制/选择文本/分享[/修改]），卡片自绘圆角背景。
- 座位菜单：模型 → V4.1-Flash / DeepSeek / DeepSeek 账号 分组 + ✓；推理等级 → Default / High / Max；权限 → 仅可查看 / 工作区内修改 / 完全权限（盾牌图标）；子面板带 ‹ 返回条，当前项蓝字 + ✓。

## 7. 主题与字号
- 浅色：bg #FFFFFF、卡片 #FFFFFF/#F5F5F5、用户气泡 #EDF3FE。
- 深色：bg #0F0F0F、卡片 #242424、chip 未选中 #283142、用户气泡 #283142。
- 字号令牌 fontScale：0.80 ~ 1.20，1.0（标准）落在滑轨正中；Theme.text/strong/mono 统一乘系数；「跟随系统」开关时锁定 1.0。

## 8. 保留的原生能力（模板没有）
- 审批条（工具执行前 允许/拒绝）、反问 Flow 卡、工具调用折叠卡、归档箱、连接设置（地址/Token/设备）、图片与文件上传、SSE 流式、Markdown 代码块。
- 模型 / 推理等级 / 权限 三处座位真实写回后端参数。

## 9. 构建
- build.sh：SDK 路径改用 pwd -W（原生 Windows 工具不认 /c/... MSYS 路径，否则 aapt2 报 failed to open APK: I/O error）；版本号改为 VERSION_CODE / VERSION_NAME 变量，默认 6 / 0.5.0。
- 流程不变：aapt2 compile → aapt2 link(生成 R.java) → javac --release 8 → d8(build-tools/android-16) → classes.dex 塞根目录 → zipalign → apksigner(debug.keystore)。

## 10. 已知差异 / 未复刻
- 官方「朗读音色」为云端音色选择，本机只有系统 TTS 引擎，行存在但只弹系统语音提示。
- 服务端检索、PoW 签名、官方语音输入（ASR）未复刻；「检查更新」为本地版本提示。
- 官方搜索为服务端全文检索，本机为本地标题/摘要过滤。
