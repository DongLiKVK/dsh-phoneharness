# 在线主机（多主机管理）· v0.5.4 变更说明

> 需求：把设置里的「数据管理」改名为「在线主机」；一个 PhoneHarness 能同时管多台电脑上的 harness；
> 列表里能看到所有主机在线状态；点任意一台就切到它的工作台和归纳箱。

- 版本：versionCode 10 / versionName 0.5.4
- 产物：android/bin/dsh-phone.apk（831,429 B，已同步 plugin/assets/dsh-phone.apk）
- 构建：android/build.sh 七步全过（aapt2 → R.java → javac --release 8 → d8 → classes.dex → zipalign → apksigner）

## 一、术语与映射

| 界面叫法 | 实际含义 | 落点 |
| --- | --- | --- |
| 工作台 | 首页 + 该主机的工作区会话列表 | MainActivity（不带 archive extra） |
| 归纳箱 | 该主机的归档箱 | MainActivity（archive=true 的独立页面） |
| 在线主机 | 多主机管理页 | 新增 HostsActivity |

一台主机的全部身份 = address + token + device + 该主机自己的工作区（cwd/名字）。
切主机就是把这五项一起换掉，所以不会出现「A 电脑的令牌配 B 电脑的工作区」这种串味。

## 三、在线主机页

- 顶栏：‹ 返回 · 居中「在线主机」· 右侧「N/M 在线」+ ↻（重新探测）
- 提示行：点一台主机即可切到它的工作台；长按可以打开它的归纳箱、改名或删除。
- 分组：「在线 · n」和「离线 / 检测中 · m」两张卡片
- 行：38dp 圆底 ic_host 图标 + 主机名（自定义名 → 电脑自报的 ping 名 → 地址）+「当前」蓝标 + 副标题「地址 · N ms」+ 状态圆点（绿/黄/红）+ ›
- 底部固定：＋ 添加主机
- 长按：打开工作台 / 打开归纳箱 / 重命名 / 删除这台主机 / 取消

## 四、四条链路

1. **探测**：进页面即对每台主机并发 GET /v1/ping（Api.call 用该主机自己的地址+令牌），记录延迟与远端名字；probeSeq 防串（连续刷新只认最后一次）。
2. **添加**：名称（可选）/ 地址 / 配对码 → POST /v1/pair 拿 token → 写进清单 → 立刻 ping 标记在线。
3. **切换**：先把当前 Prefs 的令牌/设备/工作区写回上一条记录（captureActive），再把目标主机的 address/token/device/workspaceCwd/Name 写进 Prefs（activate），然后以 FLAG_ACTIVITY_CLEAR_TOP 重开 MainActivity（长按可直接带 archive=true 打开该主机的归纳箱）。
4. **删除**：删的是当前主机时，自动切到剩下第一台；一台不剩就清空连接并跳回配对页。

## 六、兼容与回退

- 老用户（升级前只有一台主机）：首次打开「在线主机」时 adopt() 把当前连接补进清单，名称留空，标题回落到电脑自报的 ping 名。
- 旧版本把地址写进 name 的脏数据：isAddressName() 能识别，显示时跳过它直接显示 ping 名。
- 回退：把 HostsActivity/MainActivity 的改动退掉即可，Prefs 里的 hosts 键不影响单主机的旧逻辑（address/token 仍是唯一真源）。
